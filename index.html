❓ 使い方ガイド

1. 全体の流れ

このツールは「ブラウザで人間がやる操作」をノードに並べて矢印でつなぐと、それを再現する Playwright (Python) のプログラムを書き出します。書き出したコードを自分のPCで実行すれば、同じ作業を何百回・何千回でも自動で繰り返せます。

  1. 開始ノードに、最初に開くURLを入れる
  2. やりたい操作のノード（クリック／入力／情報取得／ダウンロード…）を足す
  3. 各ノードで スクショに赤枠 を引き、HTMLを貼ってセレクタを推定
  4. ノードの右の●から次のノードへ矢印をつなぐ
  5. ⚡ コード生成 → コードをコピーして実行

2. セレクタって何？

プログラムは画像を見て「このボタン」を判断できません。ページの中の場所を表す住所のような文字列がセレクタです（例：#login-btn）。
このツールでは、開発者ツールでコピーしたHTMLを貼り付けると、壊れにくいセレクタの候補を自動で並べて提案します。赤枠のスクショは「人間が後から見て分かるようにするためのメモ」として保存され、生成コードにもコメントとして残ります。

開発者ツールでHTMLをコピーする手順
  1. 対象のボタンを右クリック →「検証」（Inspect）
  2. ハイライトされた行を右クリック → Copy → Copy outerHTML
  3. ツール内の「HTMLを貼り付け」に Ctrl+V

3. 変数（前のノードの結果を使う）

情報取得ノードで取り出した値には名前（変数名）を付けられます。以降のノードの文章欄で {{変数名}} と書くと、その値が差し込まれます。

  • {{商品名}} … 情報取得ノードで付けた名前
  • {{index}} … 繰り返しの何番目か（1から）
  • {{item.タイトル}} … 一覧取得＋繰り返しのときの各項目
  • {{today}} / {{now}} / {{timestamp}} … 日付・時刻
  • {{page_title}} / {{page_url}} … 今開いているページ
  • {{last_download}} … 直前にダウンロードしたファイルのパス

フォルダ名にも使えます。例：出力/{{today}}/{{商品名}} と書けば、日付と商品名でフォルダが自動的に分かれます。

4. 何百回・何千回まわすには

繰り返しノードを使います。出口が2つあり、くり返すにつないだ側が本体、終わったらにつないだ側がループ後の処理です。

  • 回数を指定 … 単純にN回
  • 一覧の各項目 … 「一覧取得」で集めた行の数だけ
  • CSVの各行 … 手元のCSVの行数だけ（URL一覧を流し込む用途に最適）
  • 画面に並んだ同じ要素の数だけ … 並んだボタンやリンクを1番目→2番目→3番目…と順番に押していく操作用。本体のクリックノードで「複数見つかったとき → 🔁 繰り返しの何件目かに合わせる」を選びます。別ページへ移動する場合は、本体の最後に「ページ移動：前のページへ戻る」を入れて一覧に戻します（サンプル「並んだリンクを順番にクリック」参照）
  • ページ送り … 「次へ」ボタンが無くなるまで自動で進む

6. データの保存先

フローはブラウザ内（IndexedDB）に自動保存されます。別のPCで使ったり共有したりする場合は 📤 エクスポート でJSONファイルとして保存し、📥 インポート で読み込んでください。画像も含めて1ファイルにまとまります。
サーバーには何も送信されません。すべてブラウザの中だけで動きます。

7. 実行のしかた（2通り）

A. 「▶ 実行」ボタン（かんたん・おすすめ）
画面右上の「▶ 実行」から、PCに置いた実行環境（wam_runner.py）に接続すると、この画面から直接実行できます。実行するとPC上でブラウザが立ち上がって実際に動き、ログがリアルタイムで流れ、フォルダに結果が溜まっていきます。初回だけ Python のインストールと実行環境の起動が必要です（手順は▶実行の画面内に表示されます）。

B. コードを自分で実行する

pip install playwright python-docx openpyxl
python -m playwright install chromium
python scraper.py

どちらの場合も、最初は ヘッドレス＝オフ（ブラウザが見える状態）で動かし、意図通りか確認してからオンにするのがおすすめです。

7.5 実行の様子を「見る」2つの方法

  • ▶ プレビュー（キャンバス上部のボタン） … 実行前に、フローが動く順番を紙芝居のように確認できます。各ノードに付けたスクショが順に並びます。
  • 実行レポート … 実行すると output/run_report.html に「実際に開いた画面」が1ステップずつ画像つきで記録されます。実行中にブラウザで開くと5秒ごとに自動更新されるので、ヘッドレス実行でも進み具合が見えます。開始ノードの「実行レポートを作る」でオン／オフできます（既定はオン）。

8. 使うときの注意

  • 対象サイトの利用規約・robots.txt を確認してください。自動アクセスを禁じているサイトがあります。
  • 待機時間を極端に短くすると相手のサーバーに負荷をかけます。開始ノードの「1件ごとの待ち時間」を適切に設定してください。
  • ログインが必要なサイトでは、IDやパスワードをコードに直書きせず、環境変数を使う設定にできます（入力ノードの「環境変数から読む」）。

▶ 実行（自分のPCで本当に動かす）

⚪ 未接続

ブラウザ単体では他のサイトの操作やフォルダへの保存ができないため、 PCに小さな「実行環境」（Pythonファイル1個）を置いて、そこと通信して実行します。初回だけ以下の準備が必要です。

  1. Python を入れる（済んでいれば飛ばす）… python.org から。Windowsは「Add python.exe to PATH」にチェック。
  2. 📥 実行環境ファイルをダウンロード（wam_runner.py）
  3. ダウンロードしたファイルをダブルクリック（またはターミナルで python wam_runner.py）。
    • 初回だけ「いまインストールしますか？ [y/N]」と聞かれます → y と打って Enter。数分かかります。
    • 準備ができると黒い画面が開いたままになり、自動でこのページが開き直されて接続されます。あとは「▶ このフローを実行」を押すだけです。
自動で接続されないとき（手で入力する）

黒い画面に大きく出ている 接続コード（8文字）を下に入れて「接続」を押してください。ファイルを置いた場所にできる 接続コード.txt にも同じものが書かれています。

実行環境は 127.0.0.1（このPCの中）だけで待ち受け、接続コードを知らないWebページからは実行できません。黒い画面は実行が終わるまで閉じないでください。
